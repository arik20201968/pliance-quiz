# Test de Pliance, Tracking y Augmenting

Un quiz interactivo sobre **Conducta Gobernada por Reglas** basado en los conceptos de Pliance, Tracking y Augmenting de la Terapia de Aceptación y Compromiso (ACT).

## 🎯 Características

- **30 preguntas** sobre conceptos fundamentales de ACT
- **Respuestas aleatorias** para prevenir memorización
- **Tema día/noche** con toggle automático
- **Diseño responsive** para móviles y tablets
- **Barra de progreso** en tiempo real
- **Feedback inmediato** con respuestas correctas
- **Atajos de teclado** para mejor experiencia

## 🚀 Funcionalidades

### 🎨 Interfaz
- Tema claro/oscuro con detección automática del sistema
- Diseño responsive que se adapta a cualquier dispositivo
- Animaciones suaves y transiciones elegantes
- Accesibilidad mejorada con soporte para lectores de pantalla

### 🎲 Sistema de Preguntas
- **Aleatorización**: Las opciones se mezclan automáticamente
- **Progreso visual**: Barra que muestra preguntas respondidas
- **Mezcla inteligente**: Botón para reordenar sin perder progreso
- **Evaluación detallada**: Feedback específico para cada respuesta

### ⌨️ Atajos de Teclado
- `Ctrl/Cmd + Enter`: Evaluar examen
- `Ctrl/Cmd + R`: Reiniciar quiz
- `T`: Cambiar tema día/noche

## 📱 Compatibilidad

- ✅ Chrome, Firefox, Safari, Edge
- ✅ iOS Safari, Chrome Mobile
- ✅ Tablets y dispositivos móviles
- ✅ Modo oscuro del sistema
- ✅ Reducción de movimiento (accesibilidad)

## 🎓 Contenido Educativo

El quiz cubre los siguientes conceptos:

### Pliance
- Cumplimiento social mediado por consecuencias sociales
- Contra-pliance y rebeldía
- Riesgos clínicos del pliance excesivo

### Tracking
- Seguimiento de reglas basado en contingencias naturales
- Tracking efectivo vs inefectivo
- Relación con el ambiente físico

### Augmenting
- Modificación del valor de estímulos
- Augmenting motivacional vs formativo
- Aplicaciones terapéuticas

## 🛠️ Tecnologías

- **HTML5** semántico
- **CSS3** con variables personalizadas y flexbox
- **JavaScript ES6+** con módulos y async/await
- **LocalStorage** para persistencia de preferencias
- **Media Queries** para diseño responsive

## 📊 Sistema de Evaluación

- **Puntuación**: Porcentaje basado en respuestas correctas
- **Niveles**:
  - 90%+: Excelente dominio
  - 70-89%: Buen dominio
  - 50-69%: Necesita repaso
  - <50%: Requiere más estudio

## 🚀 Uso

1. Abre `pliance.html` en cualquier navegador moderno
2. Lee las instrucciones y responde las preguntas
3. Usa el botón "🔀 Mezclar" para reordenar opciones
4. Evalúa tu conocimiento con el botón "Evaluar Examen"
5. Reinicia para intentar nuevamente con preguntas mezcladas
